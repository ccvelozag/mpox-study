# Mpox Study – Statistical Analysis Code

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.21845001.svg)](https://doi.org/10.5281/zenodo.21845001)

## Overview

This repository contains the statistical analysis code associated with the Mpox study and has been made publicly available to support transparency and reproducibility of the analyses.

The public GitHub repository is available at:

**https://github.com/ccvelozag/mpox-study**

The archived version associated with the study is permanently available through Zenodo:

**DOI:** [10.5281/zenodo.21845001](https://doi.org/10.5281/zenodo.21845001)

---

## Available Materials

The publicly available materials include:

* Final study protocol and publicly releasable amendments.
* Statistical analysis plan.
* Statistical analysis code used for the reported analyses.

The statistical analysis code includes analyses related to:

* descriptive characteristics of the study population;
* adverse events;
* cohort and trial-group analyses; and
* immunogenicity.

## Data Sharing Statement

The final study protocol and publicly releasable amendments, statistical analysis plan, and statistical analysis code used for the reported analyses will be publicly available through the GitHub repository:

**https://github.com/ccvelozag/mpox-study**

The archived version of the statistical analysis code is available through Zenodo:

**https://doi.org/10.5281/zenodo.21845001**

Deidentified individual participant data underlying the results reported in the Article are **not publicly available for unrestricted download** because of participant confidentiality and applicable ethical, legal, institutional, and data-protection requirements.

Deidentified participant-level data will be available through **controlled access beginning 3 months after publication and for 5 years thereafter**.

Data may be shared with qualified researchers for scientifically appropriate analyses following:

1. submission of a methodologically sound research proposal;
2. review and approval of the proposal;
3. completion of a data-access agreement, where required; and
4. compliance with applicable ethical, legal, institutional, confidentiality, and data-protection requirements.

Requests for access to deidentified participant-level data should be directed to:

**Prof. Carlos Arturo Álvarez-Moreno**
Universidad Nacional de Colombia
Email: **[caalvarezmo@unal.edu.co](mailto:caalvarezmo@unal.edu.co)**

## Participant-Level Data

No individual-level participant dataset is included in this public repository or in the public Zenodo archive.

Participant-level data are managed separately from the publicly available analysis code and are subject to controlled-access procedures.

Researchers interested in obtaining access to deidentified participant-level data should contact Prof. Carlos Arturo Álvarez-Moreno at **[caalvarezmo@unal.edu.co](mailto:caalvarezmo@unal.edu.co)**.
